Recipes are optional **hints**. The engine can start from a naked PDB plus `--objective`.

| File | Protein | Objective in the example |
|------|---------|--------------------------|
| `dltb.yaml` | DltB (6BUG) | `discover_states` |
| `b2ar.yaml` | β2AR (3P0G) | `conformational_shift` + CV discovery |
| `glycophorin.yaml` | Glycophorin A (1AFO) | public demo + held-out oracle target |

Do not import these from `src/adaptamem`.
